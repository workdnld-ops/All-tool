# 課程時間查詢表

從「課程時間查詢表」聊天室的 iSKI finder 移植至 All-tool；原始 Sites 專案不變。保留課程解析、SB／SK／自主訓練、班別連動、1／2／4 週及純文字格式，改成與工具箱相同的原生 HTML／CSS／ES modules，不加入 Next 或新的套件依賴。

- 入口：`/apps/course-finder/`，具有工具箱按鈕與手機可收合的篩選區。
- 資料：`GET /api/course-calendar?selected=YYYY-MM-DD,YYYY-MM-DD`，Cloudflare Pages Functions 在伺服器端讀取 iSKI 公開課表。只查詢 location_id=1 的內湖與瑞光；舊版 start/weeks 參數仍相容。
- v1.2.0：週次以日期區間複選，固定五個選項，以台灣時間每週一 14:00 為換週切點（之前維持上一批，之後淘汰最舊週並加入新週）。預設前兩週，允許不連續選取，全部取消不發出請求；全選時換週保持全選，部分選取保留仍有效的週，全部過期則選第一週。前景每 30 秒及返回頁面時檢查切點，僅換週時重新查詢。結果與複製文字在不同週之間加分隔線，CSV 維持結構化列。跨年區間顯示完整年份，無重複的查詢期間。
- 查詢以台北日期為準，保留原站顏色判定，畫面只列彩色且尚未開始的時段，並明確提示部分週次讀取失敗。
- 固定上游網址，不接受任意代理網址、不登入、不讀取私人帳號、不寫入 Firebase；篩選只存在當次頁面。
- v1.2.1：各週分開查詢並逐週顯示，某週逾時不隱藏其他週。前端每週請求（含回應本文）15 秒截止，切換週次可沿用 60 秒內成功資料，重新整理會重新查詢。每次最多三週並行。
- Cloudflare handler 與待處理 I/O 限於單次 request，避免跨 request 共用未完成的 Promise；僅透過 Cache API 共用序列化資料（60 秒）。後端每週整體 10 秒截止，快取讀寫各最多等待 500ms，快取故障仍可查詢原站。原站網址使用 `filter_time=YYYY/MM/DD`，解析後仍只保留內湖／瑞光。切換篩選不呼叫 API，背景不輪詢課表。
- 根目錄 `_routes.json` 僅將課表 API 交給 Functions，其他工具維持靜態服務。根 Service Worker 不攔截本工具與 API；離線時顯示錯誤，不把舊課表當作即時可預約資訊。
- `npm test` 包含原始解析／篩選案例與 API 範圍、快取、去重、故障及輸出格式回歸測試。
- 本機完整預覽需使用 `wrangler pages dev deploy`（先 `npm run build`）；單純的靜態檔案伺服器不提供課表 API。Git 整合部署會自動編譯根目錄 `functions/`，不需另外部署 Worker 或設定金鑰。

彩色只代表原站未以灰色標示，實際開課及名額仍以 iSKI 原站為準。原站 HTML 格式變更時解析會報錯，需再更新解析規則。
