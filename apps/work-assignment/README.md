# 庶務工作 v1.5.0

## 入口與架構

- 工具箱「庶務工作」→ `/apps/work-assignment/index.html`。
- 原生 HTML、CSS、ES modules，沿用其他獨立工具的淺色設計。工作使用分類色彩卡片，桌面雙欄、手機單欄；工作名稱不再直接開啟編輯。
- `app.mjs` 處理畫面與操作；`model.mjs` 為不依賴 DOM 的資料模型、驗證與統計；`storage.mjs` 處理 Firebase 與本機測試。
- 圖示從專案既有 lucide-react 產生為靜態 SVG，沒有新增執行期 UI 套件。可執行 `node scripts/generate-work-icons.mjs` 重新產生。

## 資料儲存與安全

- 正式環境沿用 Firebase Realtime Database：`users/single-user/workAssignment`。
- 工作、分類、同仁均使用獨立 ID；改名或轉移分類不改 ID。
- schemaVersion 1；沿用 assigneeId 與 collaboratorIds 保存多位負責人，新增可選 shared（共通分擔）及 logs（執行紀錄）。舊資料缺少這兩個欄位時視為非共通、無紀錄，不需重置或覆寫。
- 所有寫入透過 `runTransaction` 對最新狀態執行單一命令；不以篩選結果或舊畫面陣列覆蓋資料。還原備份要求修訂號一致。
- 只在路徑完全不存在、且本機沒有舊快照時初始化。初始化本身也是交易，因此多裝置同時開啟不會重複建立 44 項。刪空工作仍保留初始化標記，不會重新補回。
- 新功能不搬移、不改寫其他工具資料，無需既有資料遷移。未知 schemaVersion 拒絕讀寫，不能以預設內容取代。
- 本機快照 key：`ops-work-assignment-snapshot-v1`。已載入頁面斷線後只供查看／匯出，重新連線才允許編輯。這不是完整離線 PWA，離線冷啟動仍需要頁面與 Firebase SDK 資源。
- localhost 使用隔離的 `ops-work-assignment-preview-v1` 本機資料，完全不連 Firebase。兩種儲存都不依賴部署版本，因此重新部署不會重置紀錄。
- 延續目前專案的 single-user 共用架構，沒有新增登入或變更 Firebase 安全規則。正式站使用者共用同一份資料，不是個人帳號隔離。

## 行為

- 分類以可直接點選的分類列切換並顯示各類總數；其他篩選與排序預設收合。新增工作預選目前分類。
- 卡片顯示精簡分類按鈕，點擊開啟編輯；長備註只預覽一行，完整內容保留於編輯視窗。

- 初始為 44 項工作、七分類、零位同仁；全部未分配、未評估。未預設任何同仁或星數。
- 工作名稱相同、正規化後相同、長名稱包含或相似度較高時提示；使用者勾選確認後可保留。
- 星級為 null 或 1～5。介面不再顯示平均星數，保留工作數、已評估、星數總和、未評估統計。
- 負責人可多選；共通分擔與個人名單互斥，未選擇即為未分配。多人工作列入各負責人統計，共通分擔獨立列出、不歸入每個人的負擔。
- 同仁管理列出每人的實際工作，可點選查看工作紀錄。紀錄次數是該工作的總次數，不代表個人完成次數。
- 新增紀錄可多選實際執行同仁，記錄 executorIds（固定同仁 ID）。未指定及舊紀錄不推測執行人，也不計入個人歷史。每筆紀錄對每位勾選的同仁各算一次。
- 「本機預設同仁」保存一位在職同仁的固定 ID 至 localStorage（ops-work-assignment-default-executor-v1），不寫入 Firebase 或 JSON 資料備份，不影響其他裝置。重新開啟會自動帶入快速紀錄及新增／補登紀錄，不會更動工作負責人或舊紀錄。改名後仍關聯同一人；停用、刪除或不存在時不帶入，也不擅自改選其他人。選「不預設」可清除。瀏覽器拒絕儲存時會提示僅當次有效。
- 「只看這位同仁的工作」依本機預設同仁篩選主要或共同負責工作，不包含僅曾執行或共通分擔的工作。可與搜尋、分類及難度篩選交集使用；更換預設同仁立即更新，本次執行同仁的臨時選擇不影響此篩選。無有效預設時不會意外顯示全部工作。勾選狀態與其他篩選相同，僅當次頁面有效，重置篩選可取消。
- v1.6.0：工作卡片採緊湊布局，寬桌面四欄、一般桌面三欄、平板兩欄、手機單欄；紀錄數量與快速紀錄整合到負責人旁。
- 「本次執行同仁」仍可臨時多選或清空，此覆寫只留在當次頁面，重新開啟恢復本機預設。卡片「記一次」直接記下目前時間；未指定時仍可記錄並稍後補選，不從工作負責人推測。兩秒內同一工作重複點擊不會新增兩筆。瀏覽器與安裝版 PWA 的儲存空間若不同，須各自設定；清除網站資料亦會清除此偏好。
- 「工作紀錄」分頁依裝置當地日期分組，可依日期、同仁及工作名稱／備註即時篩選，每次顯示 50 筆並可載入更多。
- 所有新舊紀錄皆可修改時間、備註及實際執行同仁，刪除前需要確認。保留原紀錄 ID、建立時間，修改另記 updatedAt；以紀錄指紋防止覆蓋其他裝置剛修改的版本。同仁執行統計即時重新計算。
- 快速紀錄的空白備註以「完成工作」儲存，維持舊版資料驗證相容；介面隱藏此預設文字，編輯時可自由補充。
- 同仁管理另外顯示「實際執行紀錄」，依工作分組顯示次數、最近日期；展開可查看所有日期時間與內容。改派、改名及停用／軟刪除同仁均不改寫過去的執行人。
- 每項工作的「紀錄」可逐筆新增執行日期時間及內容，按日期由新到舊顯示；改名、轉移分類、改派負責人均保留紀錄。時間以裝置當地時間輸入、ISO UTC 儲存；JSON 備份包括全部紀錄。
- 同仁停用／刪除是保留 ID 的狀態變更，會提示保留負責人、改為未分配或改指派其他在職同仁。刪除後若仍有工作，仍出現在負擔統計與原負責人欄位。
- 同仁總人數包含停用但未刪除者。工作總覽與負擔統計為完整資料，不隨清單篩選縮減。
- 分類刪除前若有工作，必須選擇轉移分類；至少保留一個分類。
- 手動工作排序在未篩選的「手動排序」模式中，從各工作的操作選單上移／下移。分類以箭頭調整順序。
- JSON 為完整備份；匯入先驗證格式、版本、ID、關聯、數值與日期，再顯示確認。確認時下載「還原前」備份，雲端原子取代僅限此工具。

## 測試與部署

在 All-tool 根目錄執行：

```powershell
npm test
npm run build
```

- `tests/work-assignment.test.mjs` 覆蓋初始化、重載、CRUD、重複提示、分類／同仁關聯、星級、統計、篩選排序、備份驗證與儲存失敗。
- `scripts/prepare-deploy.mjs` 將本工具複製到 deploy，不變更其他工具的來源。
- 工具箱 SW 對本工具網路請求直接放行，避免快取舊版。SW 更新時只清自己的 ops-toolbox-* 快取，保留其他工具的 PWA 快取。
