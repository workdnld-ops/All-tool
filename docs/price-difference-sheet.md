# 補差價 Google 試算表設定

資料來源：https://docs.google.com/spreadsheets/d/1_EZBxqaQWrHpwCDNTTGyWWMzEMZsUQxw2NGQjFKo7_s/edit

試算表需維持「知道連結的任何人可檢視」。工具箱本身的登入保護不變；價目試算表為公開讀取，請勿放入學員資料或其他機密。網站不需要 Google 密碼或 API 金鑰，也不會修改試算表。

## 各分頁用途

- 課程價目：A 課程名稱、B 方案堂數、C 方案總價、D 非會員單堂價、E 會員單堂價、F 方案單堂價／套裝參考單堂價；H 套裝名稱、I 方案原價、J 套裝價、K 折扣比例。A:F 的套裝參考列，B:E 留空、F 用公式保留完整精度。幼幼開頭的基本課程放在幼幼分類，其餘基本課程放在一般。
- 換算規則：A 原課程名稱、B 分類。每個名稱須在「課程價目」A/F 具有同名參考列；C 欄舊換算公式不再供網站讀取。
- 計算設定：折扣預設值、上下限、按鈕增減幅度、計算與顯示的捨入方式、CRM 相容開關。

保留「課程價目」、「換算規則」、「計算設定」的第一列欄位標題。舊「套裝價目」分頁不再供網站讀取。各分頁最多 200 筆；課程名稱、設定名稱不可重複。新增課程或套裝可在對應欄位新增列，但公式引用也需自行維護。

## 公式與規則

公式由 Google Sheets 計算，網站只讀取計算結果，不執行儲存格內的程式碼。數值或公式錯誤、欄位遺漏、重複名稱會阻止整份價目套用。

數字捨入支援「保留原值」、「四捨五入至整數」、「截斷至整數」，或將整數改為「小數1位」至「小數6位」。原課程單堂價與套裝換算單堂價均應設為「保留原值」，對齊「補價差計算機(全體同仁)」直接使用完整單堂價的算法。若想保留小數，F 欄公式本身也不能先將小數捨去。CRM浮點尾點相容接受 TRUE 或 FALSE。

「小全套分攤堂數」由課程價目 F 欄的公式引用；變更後需確認公式結果有隨之變更。套裝比例由 K 欄公式處理，網站不會再乘一次比例。

以下三個行為目前保留固定值，改成其他值會顯示不支援，而不是悄悄忽略：
- 差額小於或等於0：無需補價差。
- 全套原課程價格類型：單堂方案/套裝價。
- 目標單堂數量為0：不計算。

## 更新與故障處理

每次開啟頁面會透過受工具箱登入保護的 `/api/price-difference-config` 讀取三個分頁。頁面回到前景且距離上次同步超過一分鐘也會更新；持續停留在頁面時可按「更新價目」。Google 自身仍可能有短暫資料更新延遲。

伺服器與瀏覽器不儲存長期價目快取。離線、讀取失敗或格式錯誤時會暫停計算和複製，不會默默使用內建舊價格。修正試算表／網路後按「更新價目」即可。同步會保留仍存在的課程選擇及數量，折扣依新上下限調整。

`calculator.mjs` 的內建快照僅保留為向下相容及測試基準；正式頁面一律使用驗證通過的試算表設定。
